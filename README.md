# FORMA — Personal Fitness Journal

Автономний веб-додаток без серверної частини, акаунтів та зовнішніх бібліотек. Мова інтерфейсу — українська.

## Запуск

### Найпростіше на комп'ютері

1. Розпакуйте архів.
2. Відкрийте термінал у папці `forma-app`.
3. Запустіть `python -m http.server 8000` (або `py -m http.server 8000` у Windows).
4. Відкрийте `http://localhost:8000` у браузері.
5. Дочекайтеся першого завантаження. Після цього файли додатка кешуються для автономного відкриття в тому самому браузері.

### Телефон та доступ із різних пристроїв

Розмістіть усю папку як статичний сайт на HTTPS-хостингу (наприклад Netlify Drop або GitHub Pages). Відкрийте адресу в браузері телефону, після першого завантаження встановіть на головний екран через меню браузера. Дані не синхронізуються між пристроями. Для перенесення скористайтеся **Налаштування → Експорт JSON** і **Імпорт JSON** на іншому пристрої.

`file://` не підтримує service worker, тому просто подвійний клік по `index.html` не забезпечує повноцінну офлайн-роботу PWA.

## Функції

- Харчування: облік продуктів за масою, КБЖВ, швидкі шаблони, додавання власних продуктів, редаговані добові цілі.
- Тренування: триденний Full Body, журнал робочих підходів, ваг, повторень, нотаток та історія.
- Прогрес: вага, талія, груди, стегна, графіки, фотографії прогресу (локально).
- Сон: години, якість, нотатки, історія.
- Резервні копії: повний експорт та імпорт JSON (включно з фотографіями).

## Приватність та обмеження

Усі дані зберігаються в IndexedDB поточного браузера, фото стискаються перед збереженням. Дані **не передаються на сервер**. Видалення даних сайту/браузера може стерти записи. Регулярно експортуйте резервну копію. Якщо збережено багато фото, файл JSON може бути великим.

Це MVP: немає хмарної синхронізації, штрихкодів, автоматичної бази продуктів, нагадувань або AI-аналізу. Харчова цінність шаблонів приблизна — звіряйте з етикетками.

## Програми та база вправ

У розділі «Зал» доступні 73 вправи з пошуком і фільтрами за групою м’язів та обладнанням. Чотири шаблони: Full Body (3 дні), старт у залі (2 дні), верх/низ (4 дні), Push/Pull/Legs (3 дні).

Створюйте або копіюйте програми, додавайте та видаляйте дні, редагуйте назви вправ, навантаження й порядок. Кнопка «+ До дня» додає вправу з каталогу до обраного дня. Власну назву можна ввести в редакторі. Перед перемиканням дня або програми натисніть «Зберегти зміни програми». Підходи з різними вагами записуйте окремо; одиницю (повторення, секунди, хвилини) вибирайте у формі запису.

Програми зберігаються локально й входять до експорту JSON. Старі резервні копії підтримуються: для них автоматично створюється стандартна програма. Видалення програми не видаляє історію тренувань.
